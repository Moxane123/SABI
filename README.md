# SABI

## What is SABI?
SABI is an evidence-based professional identity platform that helps people document completed work, attach proof, collect client confirmation, and build a portable professional history.

## The Problem
Many people's work history is scattered across phone galleries, messages, social media, documents, and word-of-mouth. This makes it difficult to prove their skills and experience when new opportunities arise.

## The Solution
SABI turns completed work into structured professional proof.

Users can:
- Create a professional profile
- Document completed work
- Attach images, documents, and project links as evidence
- Request client confirmation
- Build a documented professional history
- Share a public proof profile

## Trust Model
SABI uses three clear work statuses:

Self-documented → Evidence-backed → Client-confirmed

Users cannot mark their own work as client-confirmed.

## Core Idea
SABI is not a CV builder, LinkedIn clone, or traditional portfolio.

It focuses on one question:

"What have you actually done?"

## Tagline
What you can do should count.
